# Ooho Coupled Density Snapshot

Saved before the CDP-inspired waveset LOGOS experiment.

## Sketch

- Snapshot: `ooho_combined_coupled_density_snapshot/ooho_combined_coupled_density_snapshot.ino`
- New experiment fork: `ooho_combined_waveset/ooho_combined_waveset.ino`

## What This Snapshot Contains

- Four-stream LOGOS with cloud patterns: `stutter`, `arp`, `scrub`, `scatter`.
- Close voice-forward gain and LOGOS compression.
- LOGOS macro-density modes: `sparse`, `present`, `swarm`.
- Bias toward recent recordings, so new voices enter the archive layer quickly.
- MELOS sidechain/envelope follower from LOGOS audio.
- LOGOS events force MELOS into different vocal forms.

This is the fallback if the waveset experiment becomes too glitchy or too
aggressive for the field version.
