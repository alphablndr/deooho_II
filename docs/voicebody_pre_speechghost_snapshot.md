## Why It Was Saved

The pre-speech-ghost build is the stable cleanup/articulation build where MELOS
moves mostly as a slow ambient collective body. It already includes explicit
tongue position, tongue diameter, and back/mid/front constriction, but those
movements remain slow except for normal LOGOS event nudges.

Use this snapshot if the newer speech-ghost layer feels too "speaky", too busy,
or too much like an instrument effect instead of an object voice.
